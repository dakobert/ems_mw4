# EMS MW4

Eigene Home-Assistant-Integration für das Energiemanagement: PV, Hausspeicher, Wärmepumpe, Wallbox und E-Auto, abgestimmt auf PV-Prognose und Tibber-Preise.

Stand: Phase 1 (Version 0.1.0). Liest Messwerte, bildet die Raumreferenz, speichert eine Messreihe im 15-Minuten-Raster. Steuert nichts. Einspielen über HACS als benutzerdefiniertes Repository (Typ „Integration").

- `custom_components/ems_mw4/` – die Integration
